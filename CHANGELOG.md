# Changelog

All notable changes to this project are documented in this file. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Every entry below is generated by release-please from Conventional Commits when its release pull
request is merged; do not write version sections by hand, or the next release would contain them
twice. The hand-written overview of a release (what it is, supported platforms, the API in one
screen) lives in `.github/release-notes/<version>.md`: the release workflow puts it above the
generated entry in the GitHub release.
